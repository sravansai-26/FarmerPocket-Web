POST

Create Contract

Deploys a new parametric insurance contract to the network. The contract will automatically execute when the specified oracle conditions are met.

Endpoint https://api.nexus.io/v2/contracts

Request Body

policy_holder string Required

The decentralized identifier (DID) or wallet address of the insured party.

oracle_id string Required

The registered ID of the oracle network that will provide the trigger data.

trigger_conditions object Required

The mathematical parameters defining the payout event.

metric string

e.g., "wind_speed", "rainfall_mm"

threshold number

The value that triggers the contract execution.

Responses

Example Request 
curl -X POST https://api.nexus.io/v2/contracts \
  -H "Authorization: Bearer sk_test_123" \
  -H "Content-Type: application/json" \
  -d '{
    "policy_holder": "did:eth:0x71C...",
    "oracle_id": "orc_weather_global",
    "premium_amount": 500.00,
    "payout_amount": 10000.00,
    "trigger_conditions": {
      "metric": "wind_speed",
      "operator": "gte",
      "threshold": 120.5
    }
  }'
